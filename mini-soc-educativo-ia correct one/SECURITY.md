# Política de seguridad

## Alcance

Este repositorio es una simulación estática y no procesa datos reales. Aun así, reporta de forma privada cualquier problema que pudiera:

- introducir ejecución de contenido no confiable;
- filtrar información mediante una dependencia o llamada de red;
- incluir accidentalmente credenciales o datos personales;
- permitir inyección persistente desde `localStorage`.

## Reporte

No publiques secretos en un issue. Usa el canal privado de “Security advisories” del repositorio de GitHub. Incluye versión, navegador, pasos mínimos y resultado esperado.

## Datos aceptables

Solo dominios `.example`, rangos IP reservados/privados y personas/organizaciones inventadas. No se aceptan muestras de malware ni IOCs activos.
