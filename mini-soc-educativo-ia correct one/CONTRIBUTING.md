# Contribuir

Gracias por mejorar este laboratorio educativo.

1. Crea una rama desde `main`.
2. Mantén todos los datos ficticios y seguros por diseño.
3. No agregues credenciales, IOCs operativos, malware, payloads funcionales ni datos personales.
4. Ejecuta `npm test`.
5. Verifica `index.html` desde `file://` y un servidor estático.
6. Actualiza documentación y `CHANGELOG.md`.
7. Abre un pull request con propósito, capturas y validaciones.

## Estilo

- Interfaz y documentación principal en español claro.
- JavaScript sin dependencias y sin módulos para compatibilidad `file://`.
- Controles accesibles por teclado y contraste WCAG AA.
- Todo botón visible debe tener una función real.
- Cualquier función de “IA” debe declarar su mecanismo y limitaciones.
