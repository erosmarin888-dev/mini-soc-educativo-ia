# Código de conducta

Este proyecto busca un entorno de aprendizaje respetuoso, inclusivo y seguro. Se espera lenguaje profesional, crítica centrada en el trabajo y cuidado especial al compartir contenido de ciberseguridad. No se toleran acoso, discriminación, doxxing, publicación de secretos ni instrucciones que conviertan el laboratorio en una herramienta ofensiva.

Los mantenedores pueden editar o rechazar contribuciones que violen estas normas.
